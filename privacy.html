Diese App ist eine sogenannte Trusted Web Activity (TWA) und zeigt ausschließlich die Inhalte der Website gamingpig.github.io/About-Gamingpig an. Es handelt sich um ein privates, nicht-kommerzielles Portfolio-Projekt.

1. Verantwortlicher

Gamingpig
E-Mail: gamingpig.support@gmail.com

2. Welche Daten werden erhoben?

Die Website hat keine eigene Benutzerverwaltung, kein Analytics-Tracking und keine Werbung. Voting und Wünsche funktionieren ohne Anmeldung. Dafür werden pseudonyme Browser-Kennungen und freiwillig eingegebene Texte über ntfy an GitHub übertragen und öffentlich gespeichert (Abschnitt 14). Externe Dienste erhalten technische Verbindungsdaten.

  • Es werden keine Standortdaten erhoben.
  • Es werden keine Kontakte, Fotos oder Dateien ausgelesen.
  • Es findet keine Analyse des Nutzerverhaltens (Analytics) statt.

3. Hosting & technische Zugriffsdaten

Die Inhalte werden über GitHub Pages (GitHub Inc., bzw. GitHub B.V. in der EU) ausgeliefert. Wie bei jedem Webseitenaufruf verarbeitet GitHub dabei automatisch technische Zugriffsdaten (z. B. IP-Adresse, Zeitpunkt des Zugriffs, User-Agent) im Rahmen des normalen Serverbetriebs. Diese Verarbeitung liegt außerhalb meines Einflusses; weitere Informationen dazu bietet die Datenschutzerklärung von GitHub.

4. Berechtigungen der App

Die App benötigt lediglich eine bestehende Internetverbindung, um die Website-Inhalte anzuzeigen. Es werden keine weiteren Geräteberechtigungen (Kamera, Mikrofon, Kontakte, Standort etc.) angefordert.

5. Externe Schriftarten

Zur einheitlichen Darstellung lädt die Website die Schriftarten „Inter“ und „JetBrains Mono“ über Google Fonts. Dabei stellt dein Browser eine Verbindung zu Servern von Google her. Hierbei werden technisch bedingt insbesondere deine IP-Adresse, Browserinformationen sowie Zeitpunkt und angeforderte Datei an Google übermittelt.

6. Musik-Dashboard, Stats.fm Wrapped und externe Dienste

Das Musik-Dashboard ruft aktuelle Titelinformationen über die API von npc-api.aikins.xyz ab. Liefert dieser Dienst keine aktuellen Daten, werden ersatzweise die öffentlichen aktuellen Titelinformationen des Profils gamingpig über stats.fm (api.stats.fm) abgerufen. Für Songtexte werden LRCLIB und ersatzweise eine auf Vercel bereitgestellte Schnittstelle für NetEase Cloud Music kontaktiert. Zur zuverlässigen Anzeige hochauflösender Album-Covers wird eine mehrstufige Abfragekette genutzt: Zunächst wird bei vorhandener Apple Music ID die Apple iTunes Lookup API angefragt, gefolgt vom offiziellen Spotify oEmbed-Dienst (open.spotify.com/oembed), der Apple iTunes Search API sowie einer JSONP-Suchanfrage an Deezer, bevor als letzte Stufe ein lokales Platzhalterbild angezeigt wird. Für die Spotify Wrapped / Musik-Statistiken werden ausschließlich öffentliche Aggregationsdaten des Profils gamingpig über die offizielle API von stats.fm (api.stats.fm) abgerufen. Dabei werden zu keinem Zeitpunkt persönliche Daten der Besucher an stats.fm oder Spotify übermittelt. Wie bei jedem direkten Internetaufruf erhalten die jeweiligen Schnittstellenanbieter lediglich technisch unvermeidbare Verbindungsdaten (z. B. IP-Adresse und User-Agent).

Externe Inhalte werden erst verarbeitet, wenn die jeweilige Funktion geladen oder verwendet wird. Für die Verarbeitung durch die Drittanbieter gelten deren eigene Datenschutzbestimmungen; auf deren Speicherdauer und weitere Verarbeitung habe ich keinen Einfluss.

7. Sprachausgabe (Vorlesen-Funktion)

Die Website bietet an vielen Stellen eine optionale Vorlesen-Funktion an, die nur bei aktivem Klick auf den entsprechenden Button startet. Diese Funktion nutzt die im Browser eingebaute Sprachausgabe (Web Speech API). Je nach Browser und Betriebssystem kann die Sprachverarbeitung entweder vollständig lokal auf deinem Gerät stattfinden, oder der Browser sendet den vorzulesenden Text zur Verarbeitung an einen Cloud-Dienst des jeweiligen Anbieters (z. B. Google bei Chrome-Systemstimmen). Ich habe darauf keinen Einfluss - welche Stimmen lokal oder über die Cloud laufen, entscheidet dein Browser bzw. Betriebssystem. Beim synchronisierten Vorlesen von Songtexten wird die Textsprache automatisch auf deinem Endgerät analysiert, um eine passende Sprachausgabe-Stimme zu wählen. Zudem kann die Vorlesegeschwindigkeit individuell reguliert werden. Es werden dabei ausschließlich die sichtbaren Seiteninhalte (z. B. Songtexte, Bio, Karteninhalte) vorgelesen, keine persönlichen oder eingegebenen Nutzerdaten.

8. Discord-Widget im Support-Bereich

Im Support-Bereich der Website wird die aktuelle Mitglieder- und Online-Zahl meines Discord-Servers live angezeigt. Dafür ruft dein Browser beim Laden der Seite automatisch die öffentliche Einladungs-API von discord.com auf. Dabei werden die üblichen technischen Verbindungsdaten (IP-Adresse, Zeitpunkt, Browserinformationen) an Discord Inc. übermittelt. Es werden keine Nutzerkonten oder sonstigen persönlichen Daten von dir an Discord übertragen. Weitere Informationen bietet die Datenschutzerklärung von Discord.

9. Lokale Speicherung im Browser (localStorage)

Sprache, Design, Vorleseeinstellungen, Songverlauf und Versionsstände bleiben im Browser gespeichert. Für die Roadmap werden zusätzlich ein zufällig erzeugtes Schlüsselpaar (gp_roadmap_identity_v2), noch nicht bestätigte Einträge (gp_roadmap_pending_v2) und ein Lesecache (gp_roadmap_cache_v2) in localStorage gespeichert. Der private Schlüssel wird nicht an den Dienst gesendet; der freiwillige Gerätecode enthält ihn zur Übertragung auf eigene Geräte. Öffentliche Kennung, Signatur und Eintragsinhalt werden beim Absenden übertragen. Der Cache wird beim Abgleich ersetzt, ausstehende Einträge nach GitHub-Bestätigung entfernt. Es gibt keine automatische lokale Ablaufzeit. Alte lokale Wünsche können zur Wiederherstellung vorhanden sein. Browserdaten lassen sich in den Einstellungen löschen; dies löscht keine öffentlichen GitHub-Daten und kann ohne gesicherten Gerätecode den Zugriff auf die eigene Stimme verlieren lassen.

10. Web-Push-Benachrichtigungen & Störungs-Überwachung

Die Website und PWA bietet eine freiwillige Störungs-Benachrichtigung (Web Push) an. Die Aktivierung erfolgt rein opt-in-basiert über deine ausdrückliche Zustimmung (Art. 6 Abs. 1 lit. a DSGVO). Zur technischen Zustellung von Meldungen bei API-Ausfällen generiert dein Browser einen pseudonymisierten Push-Endpunkt (z. B. über Google Firebase Cloud Messaging oder Apple Web Push). Es werden keine Namen, E-Mail-Adressen oder Geräteprofile verknüpft. Du kannst die Benachrichtigungen jederzeit mit einem Klick auf der Status-Seite oder in den Browsereinstellungen wieder deaktivieren.

Push-Endpunkt, Abonnementschlüssel und Sprache werden vor der Übertragung an ntfy mit einem zufälligen AES-GCM-Schlüssel verschlüsselt; dieser wird mit dem öffentlichen RSA-Schlüssel des Betreibers geschützt. GitHub Actions entschlüsselt die Registrierung und speichert die Gerätedaten erneut AES-GCM-verschlüsselt in data/subscribers.enc.json. Die privaten Schlüssel liegen in GitHub Actions Secrets. ntfy und GitHub verarbeiten weiterhin Verbindungsmetadaten wie IP-Adresse und Zeitpunkt. Push pausieren meldet das Browser-Abonnement ab; gespeicherte Daten und frühere Git-Historie werden dadurch nicht sofort entfernt. Frühere Versionen speicherten Geräte öffentlich; für eine Löschanfrage bitte die Kontaktadresse oben nutzen.

Privacy Policy

Gamingpig Portfolio · Last updated: September 8, 2026

This app is a so-called Trusted Web Activity (TWA) and displays exclusively the content of the website gamingpig.github.io/About-Gamingpig. It is a private, non-commercial portfolio project.

Gamingpig
Email: gamingpig.support@gmail.com

2. What data is collected?

The website has no account system, analytics tracking or advertising. Votes and wishes work without login. Pseudonymous browser identifiers and voluntarily entered text are sent through ntfy to GitHub and stored publicly (section 14). External services receive technical connection data.

  • No location data is collected.
  • No contacts, photos, or files are read.
  • No analysis of user behavior (analytics) takes place.

3. Hosting & technical access data

The content is delivered via GitHub Pages (GitHub Inc., or GitHub B.V. in the EU). As with any website visit, GitHub automatically processes technical access data (e.g. IP address, time of access, user agent) as part of normal server operation. This processing is beyond my control; further information is available in the GitHub Privacy Statement.

4. App permissions

The app only requires an existing internet connection to display the website content. No further device permissions (camera, microphone, contacts, location, etc.) are requested.

5. External fonts

For consistent display, the website loads the fonts "Inter" and "JetBrains Mono" via Google Fonts. Your browser thereby establishes a connection to Google's servers. This technically transmits your IP address, browser information, and the time and requested file to Google.

6. Music Dashboard, Stats.fm Wrapped and External Services

The music dashboard retrieves current track information via the API of npc-api.aikins.xyz. If that service provides no current data, the public current-track information of the gamingpig profile is retrieved from stats.fm (api.stats.fm) as a fallback. For lyrics, LRCLIB is contacted, and alternatively a Vercel-hosted interface for NetEase Cloud Music. To reliably display high-resolution album artwork, a multi-stage sequential query chain is used: First, if an Apple Music ID is present, the Apple iTunes Lookup API is queried, followed by the official Spotify oEmbed service (open.spotify.com/oembed), Apple's iTunes Search API, and a JSONP search request to Deezer, before a local placeholder image is shown as a final fallback. For the Spotify Wrapped / Music Statistics, only public aggregation data of the profile gamingpig is retrieved via the official API of stats.fm (api.stats.fm). At no time are personal data of visitors transmitted to stats.fm or Spotify. As with any direct internet request, the respective providers only receive technically necessary connection data (e.g. IP address and user agent).

External content is only processed once the respective feature is loaded or used. Processing by third-party providers is subject to their own privacy policies; I have no influence over their retention periods or further processing.

7. Voice narration (read-aloud feature)

The website offers an optional read-aloud feature in many places, which only starts when the corresponding button is actively clicked. This feature uses the browser's built-in voice synthesis (Web Speech API). Depending on the browser and operating system, speech processing may take place entirely locally on your device, or the browser may send the text to be read aloud to a cloud service of the respective provider for processing (e.g. Google for Chrome system voices). I have no influence over this - which voices run locally or via the cloud is determined by your browser or operating system. Only the visible page content (e.g. lyrics, description text) is read aloud, no personal or entered data.

8. Discord widget in the support section

In the support section of the website, the current member and online count of my Discord server is displayed live. To do this, your browser automatically calls the public invite API of discord.com when the page loads. This transmits the usual technical connection data (IP address, time, browser information) to Discord Inc. No user accounts or other personal data are transmitted from you to Discord. Further information is available in the Discord Privacy Policy.

9. Local storage in the browser (localStorage)

Language, design, speech preferences, recent songs and version flags are stored in the browser. Roadmap storage also includes a random key pair (gp_roadmap_identity_v2), unconfirmed entries (gp_roadmap_pending_v2) and a read cache (gp_roadmap_cache_v2). The private key is not sent to the service; the optional device code includes it for transfer to your own devices. The public identifier, signature and content are sent on submission. Sync replaces the cache and GitHub confirmation removes pending entries. Local storage has no automatic expiry. Older local wishes may remain recoverable. Clearing browser data does not delete public GitHub data and may remove access to your vote without a saved device code.

10. Web Push Notifications & Outage Alerts

The website and PWA offer optional outage and incident alerts (Web Push). Activation is strictly opt-in based on your explicit consent (Art. 6(1)(a) GDPR). For message delivery when services go down, your browser generates a pseudonymized push endpoint (via Google FCM or Apple Push Services). No personal names, emails, or device tracking profiles are linked. You can revoke and disable notifications at any time directly on the status page or via your browser settings.

Push endpoints, subscription keys and language are encrypted before transmission to ntfy using AES-GCM and the operator’s RSA public key. GitHub Actions decrypts registrations and saves device records encrypted with AES-GCM in data/subscribers.enc.json; private keys are held in Actions Secrets. ntfy and GitHub still process connection metadata such as IP addresses and timestamps. Pausing push unsubscribes the browser; stored records and historical Git revisions are not immediately erased. Earlier versions stored records publicly. Contact the address above for deletion requests.

11. Changes to this policy

This privacy policy may be updated as needed, e.g. when new features are added. The current version is always available on this page.

12. Contact

If you have any questions about privacy, you can contact me at any time by email at gamingpig.support@gmail.com.

All content, designs, logos, icons, source code, audio data, and software components provided on this website and PWA are subject to copyright: © 2026 Gamingpig · All Rights Reserved. Any unauthorized reproduction, distribution, modification, or public dissemination without prior written consent is strictly prohibited and legally protected.

14. Direct voting and public wishes through ntfy and GitHub

The purpose is shared feature planning and displaying votes and ideas across devices. No account is required. A random browser identity assigns your votes; an optional private device code lets your devices share it. This is not a verified identity of a natural person.

Voting or submitting sends an entry ID, public key identifier, signature and vote selection or name/pseudonym, category, title and description to ntfy.sh. The separate roadmap queue is publicly readable. A GitHub workflow imports valid entries into data/roadmap.json in the public Gamingpig/About-Gamingpig repository. Pseudonymous identifiers, votes and dated wishes are available across devices. Do not submit confidential or other people’s data.

ntfy is temporary storage with limited retention. An entry is durable only after the GitHub commit. The existing workflow is scheduled every 15 minutes but may be delayed. Pending entries are shown separately and can be resent. The visible roadmap reads shared data from raw.githubusercontent.com about every five minutes and on return, at most once per minute. ntfy and GitHub receive technical connection data including IP address, time and browser information.

Operating the public roadmap and displaying voluntarily published contributions relies on Article 6(1)(f) GDPR: the legitimate interest in shared feature planning and reliable display. Participation is optional; the portfolio remains available without contributing. “Understood” acknowledges the privacy notice and is not consent to additional processing.

Public records have no automatic deletion deadline; previous versions may remain in Git history. You can withdraw your vote using the same browser identity, without deleting older Git versions. To request removal of a wish or identifier, email its entry ID to gamingpig.support@gmail.com. Never send your private device code. Third-party copies, Git history and existing browser caches may require separate handling; successful synchronization replaces the local cache.

GitHub also processes data in the USA. Its own processing, retention and international transfers are described in the GitHub Privacy Statement; see also the ntfy Privacy Policy.

Subject to the GDPR, you have rights of access, rectification, erasure, restriction, objection and complaint to a supervisory authority. Contact the address above regarding our processing.

Chrome sistem sesleri için Google). Bunun üzerinde hiçbir etkim yoktur - hangi seslerin yerel olarak veya bulut üzerinden çalıştığını tarayıcınız veya işletim sisteminiz belirler. Yalnızca sayfadaki görünür içerik (ör. şarkı sözleri, açıklama metinleri) sesli okunur, kişisel veya girilen veriler değil.

10. Web Push Bildirimleri ve Kesinti Uyarıları

Web sitesi ve PWA, isteğe bağlı kesinti ve arıza uyarıları (Web Push) sunar. Etkinleştirme tamamen açık rızanıza bağlıdır (GDPR Madde 6(1)(a)). Bildirimlerin iletilmesi için tarayıcınız anonim bir push uç noktası (Google FCM veya Apple Push üzerinden) oluşturur. Kişisel isimler veya izleme profilleri ilişkilendirilmez. Bildirimleri istediğiniz zaman durum sayfasından veya tarayıcı ayarlarınızdan kapatabilirsiniz.

Push uç noktası, anahtarlar ve dil ntfy’ye gönderilmeden önce AES-GCM ve RSA ile şifrelenir. GitHub Actions kaydı açar ve data/subscribers.enc.json içinde yeniden şifreleyerek saklar; özel anahtarlar Actions Secrets içindedir. Sağlayıcılar IP ve zaman gibi bağlantı verilerini işler. Push duraklatma tarayıcı aboneliğini iptal eder; kayıtları ve Git geçmişini hemen silmez. Önceki sürümler verileri açık saklıyordu. Silme talepleri için yukarıdaki iletişim adresini kullanın.
